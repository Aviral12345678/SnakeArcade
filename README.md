# Snake Arcade 🐍

A feature-rich **Snake game** built using **Java Swing**, designed with clean
object-oriented principles and real-time keyboard interaction.

---

## 🎮 Features
- Grid-based movement system
- Snake growth mechanics
- Food spawning logic
- Wall & self-collision detection
- Pause / Resume functionality
- Restart after Game Over
- Score tracking
- Supports **Arrow keys + WASD controls**

---

## ⌨ Controls
- **Arrow Keys / W A S D** → Move snake
- **P** → Pause / Resume
- **R** → Restart game after Game Over

---

## 🛠 Tech Stack
- Java
- Java Swing
- OOP (Object-Oriented Programming)
- Event-driven programming
